A-option demo programs for the compiler

For each demo, rename it to test_code.txt, and then run it through the compiler and run the linux script to check that it works.

Sample inputs:
01_formula_demo
  2
  7
  8
  6
  Expected arithmetic result: 2 * ((8 + 6 - 10) / 2 * 4) / (7 + 3) = 1

02_largest_of_two_demo
  9
  4
  Expected result: 9

03_factorial_while_demo
  5
  Expected result: 120

04_largest_of_three_nested_if_demo
  5
  12
  9
  Expected result: 12

05_recursive_factorial_procedure_demo
  6
  Expected result: 720

06_array_sum_demo
  1
  2
  3
  4
  5
